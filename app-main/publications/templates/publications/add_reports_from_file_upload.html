Add publications from file upload

Upload an Excel file (.xlsx) with one report per row; the first row holds the column names. Only Excel files can be imported.

  • Required columns: title, authors, and number or year. Each row needs at least one author and a number or a year; the title may be left empty and filled in later.
  • Optional: type, topic, supervisors, editors, abstract, keywords, comment.
  • All or nothing: if any row has an error, nothing is imported and every problem is listed with its sheet and row.
  • A report number that already exists: the row is skipped and the existing report is not changed.

The template explains each column on its Help sheet: Report Excel file template
